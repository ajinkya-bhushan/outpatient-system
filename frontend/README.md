# DocConnect React

React implementation of the Stitch clinical documentation assistant screens.

## Run

```bash
npm install
npm run dev
```

The local development URL is `http://127.0.0.1:5173/` when started with the current Codex session.

## Screens Included

- Secure login
- Daily schedule and patient queue
- Pre-visit dashboard
- Live encounter recording
- AI note generation
- Review and edit SOAP note
- EHR sync success
- Clinical analytics dashboard
